ROS2 Sandbox

Practice ROS 2 basics in your browser

설치 없이 브라우저에서 ROS 2 기초를 연습하세요

Beginner practice only · 초보자 연습용

A simple practice space for learning beginner ROS 2 syntax: writing rclpy nodes, topics, services and parameters, and the ros2 command line. It is not a full ROS 2 environment, so complex projects such as packages, launch files, actions, TF or simulators like Gazebo are not supported.

ROS 2 초보 문법(rclpy 노드, 토픽, 서비스, 파라미터, ros2 명령)을 익히기 위한 단순 연습장입니다. 실제 ROS 2 환경이 아니므로 패키지, launch 파일, 액션, TF, Gazebo 같은 시뮬레이터 등 복잡한 구현은 할 수 없습니다.

  • Write a Python node and run it in the terminalPython 노드를 작성하고 터미널에서 바로 실행
  • Try ros2 topic · service · param commandsros2 명령 연습
  • See results with turtlesim and the node graphturtlesim 거북이와 노드 그래프로 결과 확인
