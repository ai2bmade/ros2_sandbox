1. 수집하는 정보

  • Google 로그인 시 Google이 제공하는 이메일 주소, 이름, 프로필 사진 주소
  • 가입 신청 시 직접 입력한 이름, 소속, 구분, 메모

2. 이용 목적

로그인과 이용 승인, 저장한 실습 파일 제공, 부정 이용 방지에만 사용합니다. 광고나 마케팅에는 사용하지 않으며 제3자에게 제공하거나 판매하지 않습니다.

3. 보관과 삭제

회원 탈퇴를 요청하면 7일 이내에 계정 정보와 저장한 파일을 모두 삭제합니다. 로그인 기록은 보안 목적으로 최대 90일 보관 후 삭제합니다.

4. 코드 실행

작성한 코드는 사용자의 브라우저 안에서만 실행되며 서버에서 실행하지 않습니다. 서버에는 저장을 선택한 파일만 보관됩니다.
